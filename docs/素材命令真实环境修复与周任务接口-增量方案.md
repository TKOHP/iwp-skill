# 素材命令真实环境修复与周任务接口 - 增量方案

> 状态：**已确认**（用户指令"跨仓库同时进行"，2026-10-28）
> 背景：sess_8a8c1503 真实会话复盘（skill-evaluator 分析）——素材命令首战失败
> （服务端 32KB 截断 → 客户端静默透传 str → ValueError），N+1 详情调用撞 nginx 503，
> agent 无受认可降级路径被迫写即兴脚本。

## 目标态

1. **server（InnovationWorkPlatform）**：周筛选口径单一来源化
   - 后端 `/tasks/weekly-draft` 新增 `draft_mode=raw`：复用既有筛选查询，跳过文本拼装，
     返回按课题分组的裁剪字段任务列表（含描述/进度，日期 isoformat、进度 float）；
   - MCP 新增薄工具 `list_my_week_tasks`（tasks.py 工具 #13）：代理 raw 模式，
     `user_id` 取自调用者身份（不可查他人），刻意不做 T5 列表投影（描述是本工具目的）；
   - 一次调用替代「翻页 + N+1 详情」，N+1 与 503 限流从根上消除。
2. **client（iwp-skill）**：真实环境防御 + 双路径
   - 形状收敛层 `normalize_result`：str → json.loads 归一；截断标记 → 精确报错
     （不再泛化为"返回非对象"）；PAGE_SIZE 100→20（实测安全值）；详情批间 0.2s→1s；
   - 详情失败按 2s/4s 退避重试（现场实测参数），凭证过期不重试直接上抛；
   - `build_material` 服务端工具优先、失败自动回退本地筛选，
     输出 `source`（server/local）与 `warnings` 记录降级原因；
   - cli 错误分类新增 `response_truncated`；素材命令 ValueError 精确转述；
   - W2 边界补受认可降级分支（声明降级→手动路径，禁止静默绕过统一入口）。

## 边界

- 本地筛选纯函数保留为旧 server 回退路径，口径与 raw 模式同源对齐；
- 不改 MCP_MAX_OUTPUT_BYTES；不做周报自动提交；
- server 侧验证范围：编译 + 既有契约自检；真实联调需重启 server 后执行。

## 复测集合

client 21 项单测（服务端路径/回退/形状收敛/截断/退避重试/降级/分页/用法错误）；
server 编译与注册检查；联调走查（server 重启后：`reports material` 应输出
`source=server` 且 counts 与现网 22 任务一致）。
