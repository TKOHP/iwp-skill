# 使用案例

这里是 iwp 技能的典型场景演示：每个案例展示「你说什么 → agent 做什么 → 你会看到什么」的完整交互过程。

> 案例只演示使用体验；工作流细节与规则以 `references/` 对应文件为准，工具参数以 `cli.py tools` 实时输出为准。

## 场景导览

| 案例 | 场景 | 你可以这样说 |
|------|------|-------------|
| [01 课题任务管理](01-课题任务管理.md) | 任务的查、建、改、分配、日志 | 「列出我的任务」「在课题 X 下建个任务 Y」 |
| [02 周报管理](02-周报管理.md) | 手动写周报、按任务自动生成、查询修改 | 「根据我本周的任务生成周报」「帮我写本周周报」 |
| [03 自由模式](03-自由模式.md) | 查看与调用场景路由未覆盖的 MCP 工具 | 「你能调哪些 MCP 工具？」 |
| [04 授权与排障](04-授权与排障.md) | 首次授权、重新授权、健康体检 | 「诊断 iwp」「重新授权」 |

## 阅读建议

- **第一次使用**：先读 [04 授权与排障](04-授权与排障.md)，了解授权长什么样、出问题怎么办。
- **日常使用**：按需查阅 01-03；案例间相互独立，不必按顺序读完。
