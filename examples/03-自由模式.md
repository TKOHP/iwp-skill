# 案例：自由模式

> 路由：free-mode（工作流细节见 `references/free-mode/README.md`）

## 场景

课题任务和周报之外的 MCP 工具也能用：想看看平台都开放了哪些能力，或者调用一个场景路由没覆盖的工具。

## 你可以这样说

- 「你能调哪些 MCP 工具？」
- 「XXX 工具的参数是什么？」
- 「帮我调一下 XXX 工具，参数是……」
- 「我想查一下 XX 数据，有工具能做吗？」

## agent 会做什么

1. **工具发现**：实时拉取 MCP 工具清单，按分组（课题任务 / 周报）整理成列表，每个工具配一句话说明。
2. **schema 查询**：指定某工具时，给出它的必填参数与类型摘要，不甩原始 JSON。
3. **自由透传**：
   - 你给了工具名 → agent 先查该工具的参数定义，按定义组装参数；
   - 你只描述意图 → agent 从工具说明里匹配候选，列出来让你确认，不会猜着调。
4. **写性质工具不豁免预览**：透传调 create / update / delete 类工具时，同样先给完整预览、确认后执行、执行后回读。
5. **边界**：已经属于任务、周报场景的请求（列任务、写周报等）会被交回对应场景处理——那里有更完整的确认与展示规则。

## 你会看到什么

- 分组工具清单（工具名 + 一句话描述）。
- 指定工具的参数摘要（必填项 + 类型）。
- 调用结果按数据形态渲染（表格 / 明细）。

## 常见变化与注意点

- 工具清单是**实时发现**的：MCP server 新增工具后无需更新技能即可调用。
- 报「工具不存在」时 agent 会给出名称最接近的候选。
- 某工具用得频繁、场景稳定后，可以请维护者把它迁入对应的场景路由。
- 发现与调用细节见 `references/free-mode/README.md` 与 `references/_shared/tool-discovery.md`。
