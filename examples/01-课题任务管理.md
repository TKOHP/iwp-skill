# 案例：课题任务管理

> 路由：tasks（工作流细节见 `references/tasks/README.md`）

## 场景

日常与课题任务打交道：查看自己手头的任务、给课题建新任务、更新进度、把任务分配给同事。

## 你可以这样说

- 「列出我的任务」/「我的待办」/「本周任务」
- 「在课题 XX 下建个任务 YY，月底截止」
- 「把任务 132 标记为完成」
- 「把任务 132 分配给张三」
- 「任务 132 加一条进度：已完成联调」
- 「有哪些课题？」
- 「把 132、133、135 都标完成」（批量）

## agent 会做什么

1. **查询**：自动翻页拉取全部任务，整理成表格给你。
2. **创建**：你说的是课题名称时，agent 会先查找课题；有多个相近候选会列出来让你选，不会猜。然后生成一张**全字段预览卡**（标题、紧急度、起止日期、执行者，未填项标注默认值），你确认后才真正创建，并回执新任务 ID。
3. **更新 / 分配**：同样先给预览卡（现状 → 执行后对照）。分配是**覆盖式**的——预览里会显式标出这次会移除哪些原有执行者。
4. **日志**：写进度前同样预览确认。
5. **批量修改**：逐条预览、逐条确认、逐条回执，不会一股脑批量提交。
6. 全程自动处理授权：未授权或授权过期时，agent 会自动打开浏览器引导你完成授权，回到对话即可继续。

## 你会看到什么

- 任务列表：表格（ID / 标题 / 状态 / 紧急度 / 截止），分页时标注「第 X 页 / 共 Y 条」。
- 写操作前：全字段预览区块，等你回复确认。
- 写操作后：回执（任务 ID + 关键字段），并回读核验过。

## 常见变化与注意点

- **删除任务是高危操作**，agent 会再次向你确认后才执行。
- 列表为空时 agent 会如实说明，不会编造任务。
- 提示权限不足时，联系管理员检查你在 IWP 的角色权限。
- 命令与参数细节以 `cli.py tools` 输出为准，见 `references/tasks/README.md` 与 `references/_shared/write-preview.md`。
